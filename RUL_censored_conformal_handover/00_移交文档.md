## 1. 一句话说明

在训练数据存在删失（发动机没坏就下线）、同时同一台发动机相邻循环高度相关的条件下，为在役航空发动机给出"还能安全飞多少循环"的下界，并保证覆盖率。目标是一篇 EI 会议论文。

两篇零件来源：

- Candès, Lei, Ren (2023) Conformalized survival analysis. JRSS-B. 给的是删失下的共形下界。它假设样本独立同分布。
- Javanmardi, Hüllermeier (2023) Conformal prediction intervals for RUL. IJPHM. 给的是共形预测装到 RUL 上的流程。它假设标签完整。

机队里两个假设同时不成立。这就是缺口。

## 2. 现行设计（2026-09 修正后版本，以此为准）

### 2.1 记号

- 发动机 i，循环 t = 1, …, F_i，F_i 为失效循环。
- 特征 X_{i,t}：14 个传感器当前值、最近 30 循环滚动均值与标准差、循环序号 t，共 43 维。
- 标签 RUL_{i,t} = F_i − t，封顶 125。
- 下线时刻 C_i：每台机一个，与 F_i 独立，对每台机都记录（Type-I 删失；现实含义是计划性退役日期事先已知）。
- 观测长度 O_i = min(F_i, C_i)，δ_i = 1{F_i ≤ C_i}。

### 2.2 方法

1. 定观测视野 c0。目标量换成 y = min(RUL, c0)。
2. 选择规则：保留样本 (i, t) 当且仅当 C_i − t ≥ c0。对保留样本，y 可观测。规则对失效机同样执行。
3. 权重：w(t) = 1 / S_C(t + c0)，S_C 为下线时刻的经验生存函数，用训练折全部发动机的 C_i 估计（Type-I 下 C_i 全部可观测）。分母设下限 1/训练折台数。
4. 得分 V_j = m̂(x_j) − y_j，m̂ 为梯度提升树点预测。
5. η(x) 取加权 (1−α) 经验分位数（论文一 Algorithm 1，一侧）。
6. 下界 L(x) = (m̂(x) − η(x)) ∧ c0。

### 2.3 对上一版设计的三处修正

| 上一版（`论文设计方案.pptx` / `讲稿_论文设计方案.md`） | 现行 | 原因 |
|---|---|---|
| 按发动机整机截取 | 按样本选择 C_i − t ≥ c0，删失机早期循环照样用 | 整机截取既无必要又浪费样本；样本级选择才使两群样本只差协变量分布 |
| 删失权重 × 时序权重 | 只用删失权重；同机相关用两层结构处理（一机一点 vs 全部循环两种校准，先看实验） | 时序权重无似然比含义，相乘后无任何定理覆盖 |
| 维修成本曲线 | 去掉。报覆盖率、决策区覆盖率、分段覆盖率、平均下界、无信息界比例 | 成本参数无真实来源 |

一个副产品：即使 C_i 完全随机，样本层面的删失也依赖协变量（剩余观测窗 C_i − t 随 t 缩短），所以 w(t) 不是常数。论文一"完全独立删失可不加权"在 RUL 里不成立。这是论文引言里"不能直接照搬"的第一个硬理由。`s03` 里 Cu 与 Cw 的差是它的实验证据。

### 2.4 对比线

| 代号 | 做法 | 作用 |
|---|---|---|
| E | 无删失，完整数据 | 上界参照 |
| A | 丢弃删失机 | 常见错误做法一 |
| B | 把下线当失效，标签 min(O_i − t, c0) | 常见错误做法二 |
| Cu | 选样本，不加权 | 消融：不修正 t 引起的偏移 |
| Cw | 选样本，加权 | 现行方法 |
| Cw1 | 选样本，加权，一机一点校准（重复 20 次均值） | 校准点严格可交换的版本 |

### 2.5 指标

- coverage：总体覆盖率 P(RUL ≥ L)。
- cov_dec：决策区覆盖率，只看真实 RUL < c0 的测试点。**这是最要紧的数。** 下界被 c0 封顶后，RUL ≥ c0 的样本天然覆盖，总体覆盖率会被它们抬高。
- cov[a,b)：按真实 RUL 分段 [0,15)、[15,30)、[30,60)、[60,125]。
- mean_L：有限下界的均值，衡量紧度。
- trivial：下界为负无穷的比例。

测试集用全部循环（FD001 为 13096 点），不只用最后一点。同机相关，覆盖率的不确定性按发动机数（100）衡量，不按点数。

## 8. 已知问题与下一步

### 已知问题

1. 边际保证被远离失效的样本稀释。y = min(RUL, c0) 后，多数测试点 y = c0，下界天然覆盖，(1−α) 的保证可能全花在它们身上，决策区（RUL < c0）没有单独保证。这是论文二承认的问题在这套设定下的具体形态，也是论文一 Theorem 5（条件覆盖不可能）的推论。
2. 一机一点校准点太少。FD001 校准折 40 台，删失后更少。分位数粗，下界偏保守。
3. 两层结构（发动机→循环）与删失同时存在时的精确覆盖保证，尚未推导。当前 Cw 用全部循环校准，靠实验检验。
4. FD001 单工况，没有能解释删失的协变量，只能做与协变量无关的删失。
5. 点预测器只求够用，未调参。

### 下一步（按优先级）

1. 按预测值分组做 Mondrian 校准：把校准集按 m̂(x) < c0 与否分组，分别取分位数，让决策区有自己的保证。这是对问题 1 最直接的处理，论文一第 6.2 节给了框架。
2. FD002 与 FD004 合并（509 台，6 种工况），让下线时刻分布随工况变化，做依赖协变量的删失，验证 S_C 需要条件估计的情形。
3. CQR 版本：点预测换成分位数回归，得分 q̂_α(x) − y，看紧度提升。
4. c0 的数据自适应选择：在训练折留 25% 试网格，选平均下界最大者（论文一 3.4 节）。
5. 两层结构与删失的理论：读 Dunn/Wasserman/Ramdas 2023 与 Lee/Barber/Willett 2023，写出一机一点方案的精确保证，再考虑全部循环方案的近似保证。
6. N-CMAPSS：更大、有真实飞行剖面、有部件级失效模式真值。`04_future/inspect_ncmapss.py` 已备好。竞争风险留到这一步之后。
