# 第二次课代码：运行说明

文件放在同一目录：

| 文件 | 作用 | 贴回什么 |
|---|---|---|
| `cmapss_common.py` | 公共函数，不直接运行 | 无 |
| `s00_env.py` | 环境自检：Python 与包版本、Rscript、字体文件、数据文件 | 全部输出 |
| `s01_inspect.py` | 结构探查，不建模 | 全部输出 |
| `s02_baseline.py` | 无删失基线：点预测、两侧区间、一侧下界；结果写 `results/` | 全部输出 |
| `s03_censoring.py` | 删失构造、样本量核算、六条线对比（E / A / B / Cu / Cw / Cw1）；结果写 `results/` | 全部输出 |
| `s04_figures.R` | 读 `results/` 出 11 张图到 `figures/`，宋体五号 / Times New Roman 五号 | 图文件清单 |
| `run_all.bat` | 按顺序跑完五步，日志写 `logs/` | 五个日志 |
| `requirements.txt` | Python 依赖 | 无 |

## 运行

1. 下载 C-MAPSS，把 `train_FD001.txt`、`test_FD001.txt`、`RUL_FD001.txt` 放进一个目录（其余子集有也放进去）。
2. 五个脚本顶部的 `DATA_DIR` 改成那个目录；或者不改，运行时把目录作为第一个命令行参数传进去。
3. 按顺序：

```
python s00_env.py
python s01_inspect.py
python s02_baseline.py
python s03_censoring.py
Rscript s04_figures.R
```

带目录参数的写法：`python s01_inspect.py E:\cmapss`，R 是 `Rscript s04_figures.R E:/cmapss`。

或者双击 `run_all.bat`（也可以 `run_all.bat E:\cmapss`）。Python 依赖见 `requirements.txt`；R 4.5，缺的包 s04 会自动装（ggplot2、dplyr、tidyr、showtext）。`Rscript` 要在 PATH 上，s00 会检查。CPU 即可，s03 约几分钟。

## s00 输出要核对的三件事

- numpy、pandas、scikit-learn 三个都有版本号。
- Rscript 找得到。找不到就把 R 的 bin 目录加进 PATH。
- 宋体与 Times New Roman 两个字体文件都"有"。缺任一个，s04 的图不能用于论文。

## s01 输出要核对的四件事

- 每个 train / test 文件都是 26 列，NaN 为 0。
- FD001 训练集 100 台、20631 行；测试集 100 台、13096 行；RUL 文件 100 行。
- 近零方差列（std < 0.01）对应的传感器是 1、5、6、10、16、18、19。传感器 6 只在 21.60 与 21.61 两个值之间跳，标准差约 0.001，所以判据用 0.01 而不是 0.001。列 2 到 4 是工况设置，不算传感器。
- FD001 工况组合数为 1，FD002 / FD004 为 6。工况设置带小噪声，脚本按标称间隔取整后再数（op1 取整到 1，op2 到 0.05，op3 到 10）。

任何一条不符，先停下来贴输出，不要跑 s02。

## s02 输出怎么看

- `[2]` 两侧区间覆盖率应在 0.90 附近（最后一循环那行只有 100 个点，波动大属正常）。这一步是确认与论文二的流程一致。
- `[3]` 一侧下界：对比"全部循环校准"与"一机一点校准"两行的覆盖率和平均下界。前者点多下界紧，后者点少但校准点可交换。

## s03 输出怎么看

- `[A]` 核算表：看"保留发动机(校准折)"一列。少于 30 台，一机一点方案不做。
- `[B]` 结果表，六行对应六条线：E 无删失参照、A 丢弃删失机、B 把下线当失效、Cu 选样本不加权、Cw 选样本加权、Cw1 加权一机一点。重点三处：
  - `cov_dec`：真实 RUL 小于 c0 的样本上的覆盖率。这是决策区，是唯一要紧的数。总体 `coverage` 会被 RUL 远大于 c0 的样本抬高，因为下界被 c0 封顶后那些样本天然覆盖。
  - `Cu` 与 `Cw` 的差：只差一个权重，权重来自"剩余观测窗随 t 缩短"这个事实。
  - `Cw` 与 `Cw1` 的差：只差校准点是全部循环还是一机一点。Cw1 的 `n_cal` 等于校准发动机数。
- `trivial` 不为 0 说明有测试点的下界是负无穷，通常出现在校准点很少或 t 很大的时候。
- 每个删失率开头一行"目标删失率 / 实际"，两者相差应不超过 0.03。

## 参数在哪改

- 删失率：`s03_censoring.py` 的 `CENS_RATES`
- 观测视野 c0：`C0_ACCOUNT`（核算表）、`C0_METHODS`（跑方法）
- 校准折比例：`CAL_FRAC`，两个脚本都是 0.40
- 随机种子：`SEED`，两个脚本都是 2026。删失的种子是 `SEED + 删失率 × 100`。
- 近零方差判据：`s01_inspect.py` 的 `LOW_STD`，默认 0.01。
- 重点删失率与 c0（出图用）：`s04_figures.R` 的 `FOCUS_RATE`、`FOCUS_C0`。

## 已知限制

- 删失是人工构造的 Type-I 删失：每台机的下线时刻都记录，与寿命独立。依赖工况的删失要用 FD002 / FD004，下次课做。
- 权重的分母 S_C 设了下限 1 / 训练折发动机数，避免极端权重。
- 点预测器是梯度提升树，只求够用。
